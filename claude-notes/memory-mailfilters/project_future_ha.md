Future project: a DSL (in the style of the mailfilters .fil language, not Pascal) that generates Home Assistant YAML (scripts, automations, template sensors/switches). EP mentioned this as a future project in March 2026, after the mailfilters project.

**Why:** EP wants a higher-level language to manage Home Assistant configuration rather than writing raw YAML.

**How to apply:** Use the same CDL1-inspired parser style and .fil-like DSL syntax as mailfilters. The mailfilters codebase is the direct template.
